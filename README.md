# n8n-scenarios
Рабочие шаблоны сценариев автоматизации: приём заявок, квалификация, уведомления, журнал.

## Сценарии
1. lead-intake-form-telegram-sheets.json — форма на сайте -> квалификация (3 вопроса)
   -> уведомление владельцу в Telegram -> строка в Google Sheets -> автоответ клиенту.
2. spravka-pipeline-skeleton.json — заявка студента -> сверка по HTTP-источнику ->
   черновик документа -> задача сотруднику -> уведомление о готовности.

## Как использовать
Импорт в n8n: Workflows -> Import from File. Заменить креденшелы (Telegram, Google Sheets, HTTP).
Все сценарии белые: только входящие обращения и плановые операции, без масс-рассылок.
